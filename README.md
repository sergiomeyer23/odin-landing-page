# Odin Landing Page

Landing page project for The Odin Project's Foundations course. It is an
unofficial fan page for Warcraft III: The Frozen Throne, built with HTML and
CSS.

It has a header, a hero section, a row of cards about the four races, a short
about section, a quote and a footer.

Warcraft is a trademark of Blizzard Entertainment. This page is not affiliated
with them.
